# Mr.Pizza Renewal

기존 **미스터피자 웹사이트를 리뉴얼 컨셉으로 재구성한 프론트엔드 프로젝트**입니다.  
브랜드 이미지를 현대적으로 개선하고, 제품 중심의 UI와 직관적인 메뉴 탐색 경험을 목표로 디자인 및 구현했습니다.

🔗 **Live Demo**  
https://oloklkl.github.io/mr-pizza/pages/

---

## Project Overview

- 기존 브랜드 사이트의 올드한 디자인 개선
- 제품 중심의 비주얼 강조
- 직관적인 메뉴 탐색 UX 설계
- 반응형 웹 기반 UI 구현

## 주요 기능

### 메뉴 페이지
- 피자 / 사이드 / 세트 메뉴 분류
- 메뉴 카드 UI
- 메뉴 상세 모달
- 옵션 선택 및 가격 반영

### 장바구니
- LocalStorage 기반 장바구니 기능
- 수량 변경
- 총 가격 자동 계산

### Drop 페이지
- 시즌 메뉴 소개 랜딩 페이지
- 카운트다운 UI
- 제품 중심 히어로 섹션

### Store 페이지
- 매장 정보 카드 UI
- 매장 정보 확인 기능
